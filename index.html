How do I come back and update it?

Use the same HTML file in the same browser to return to your saved entries, where local storage is supported. Before switching phones, browsers, or cleaning your device, select Download editable backup. Reopen the tool and select Restore backup to keep editing. PDF and PNG exports are for viewing and sharing, not editing. Some phone file-preview apps don't retain local data, so a backup is the safest option.
