POCKET STREAMS BUDGET — MINI CALCULATOR UPDATE

IMPORTANT: This is an upgrade to your existing website, not a new website.

HOW TO UPDATE THE GITHUB PAGES WEBSITE
1. Open the GitHub repository used for your Pocket Streams Budget site.
2. Open the existing index.html file.
3. Click the pencil (Edit this file). Select all the old code and replace it with the contents of the NEW index.html from this package, OR upload/replace index.html using the GitHub interface.
4. Click Commit changes. Your existing GitHub Pages URL stays the same.
5. Refresh the page on your phone. If an old copy appears, reload/clear the page cache (not site data).

WHAT'S NEW
- A tiny calculator icon next to each Target and Current amount.
- Tap it to enter additions, subtraction, multiplication, and division.
- Tap 'Use total' to insert the result for that exact expense and column.
- All current calculations, budget rows, autosave, editable backup, PDF and PNG exports remain.
- Storage uses the SAME localStorage key as the prior version, so on the same site and browser previous budgets should still appear.

PRIVACY
- Calculations are performed in the browser. No server connections are required.
- Save an editable backup before updating as a precaution; avoid clearing site data or changing the site URL if you want to keep locally saved budgets.
