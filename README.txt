WHAT IS NEW
- One-tap previous/next month selector and month picker

- Tiny three-dot month menu: copy a previous plan, clear only Current amounts, or reset only the selected month
- Per-bucket Target and Current changes compared with the last earlier recorded month
- Collapsible monthly trends and up to 12 recently saved monthly totals
- Editable backup now saves ALL recorded months together
- Original mini calculator, PDF, image export, and phone layout retained

UPDATE YOUR GITHUB PAGES WEBSITE
1. Before updating, open your live budget website and download an editable backup of your existing budget.
2. Open your GitHub repository (Pocket-streams).
3. Open the existing index.html file, click the pencil/edit icon, and replace its contents with the index.html in this ZIP; OR upload this index.html and replace the old file, if GitHub offers you that workflow.
4. Commit the changes on the main branch.
5. Reopen https://streamsintowealth.github.io/Pocket-streams/ and refresh.
6. Check that your saved budget still appears. The new version migrates prior single-month entries from the same URL/browser.

IMPORTANT
- Do not replace your site's repository with the ZIP itself. Extract the ZIP and use index.html.
- On the same website URL and device, previous entries should migrate into the new monthly system.
- Use 'Back up all months' regularly. Browser storage is device- and browser-specific.
- PDF/PNG exports are a snapshot of the SELECTED month; the editable JSON backup includes ALL months.
- The tool does not send financial data to Streams Into Wealth or GitHub.
- A Current figure that is lower than a prior month may simply reflect that this month is still in progress.
